GS1 function calls after event tests now retain their source order.

For `if (created) { this.n = 10; } bump();`, where `bump` increments
`this.n`, the compiler previously lifted the call into load-time code:
creation ended with 10 instead of 11. Such calls now use the existing
whole-script dispatcher, as suffix assignments already do.

Synthetic execution covers load, two named events and a direct function
call. The baseline load-time side effect and final value mismatch were
confirmed by an internal GS1/GS2 comparison on 0.2.13. No original-client
equivalence is claimed. Prefix replay, suffix commands and unnamed-event
wrapper coverage remain separate limitations. Machine direct-call behavior
is unchanged. No API change, tag or release creation is authorized here.
