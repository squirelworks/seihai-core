# 0.2.17

Adds `protocol::graal2002` with explicit descriptors for the six Windows
Graal 2002 world builds and a GS1 registered-word query. Shared tokens and
FileVersions no longer require callers of this API to conflate ver7 with
ver9 or ver13 with v22. The static command-table additions are documented
in `documentation/graal2002-capabilities.md`.

Generic GS1 eras, parser/interpreter behavior and online version profiles
are unchanged. Registration is not proof of native execution or packet
support. No new dependency or original executable/sample fixture.
