The shared client session hands the game the hits on the player, so Ato and Issho can be hurt by other players and die as Mae does.

## API

- `client::Live::hits` (`SharedHits`): other players' sword swings (by id) and the `PLO_HURTPLAYER` (40) and `PLO_HITOBJECTS` (46) the server sent, as `IncomingHits { swings, hits, others, own_cell, nickname }`. The game judges them on the victim's side with `OfflineSession::receive_all`, which takes those same fields. The network thread now drains `SessionState::swings` and `SessionState::hits`, which no client session took before.
- `IncomingHits::is_empty`.

`Live` gains one field. Every consumer in the suite builds it with `Live::default()`, so this is a patch release.

## Consumers

seihai moves to `v0.1.3` with the PR that brings being hit, health and death into seihai-play.
