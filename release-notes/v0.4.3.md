# 0.4.3

Adds an explicit-endpoint `relay::Client` for the 1.1.9 relay dialect:
separate game-wide and level TCP rooms, pairing, initial player state,
position/name/colour updates, chat, room changes and peer departure.
This is separate from the account/token-based gen-2 game connection.
Existing profiles and accepted tokens are unchanged.

This is a partial client API. The client requests its first available peer;
the relay merges whole parties and confirms every resulting member. The
generated three-client fixture checks this full-mesh delivery in both rooms.
Chat before the level identity arrives returns `WouldBlock`; callers poll and
retry instead of treating an unsent message as successful.
Callers supply local levels and regularly poll the connection.
It does not implement HTTP level retrieval, every
earlier relay dialect, leader-driven world synchronization, shared board,
NPC, item, combat or equipment state. Its resource limits and UNIX-millisecond
login clock are explicit rebuild policies; the latter does not establish
the original clock epoch or units, or implement leader election.
