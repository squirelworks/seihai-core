The GS1/GS2 compiler rewrite, plus the compiler work that led up to it.

## Breaking changes

- **`compile_script` is gone.** Use `compile(src, language, mode)`:
  - `language` is `Language::Gs1(era)`, `Language::Gs2` or `Language::Detect(era)`. Detect chooses GS1 or GS2 per script.
  - `mode` is `Mode::Strict` (the default) or `Mode::Legacy`.
- **Strict mode refuses every non-standard spelling.** Legacy mode accepts them, compiles what the script meant, and returns one warning per quirk. `compile_gs1` and `compile_gs2` are strict. (#17)
- **A `new T(x) { ... }` block used as a value is now an error.** Its body used to be dropped silently. Otherwise the output is byte-identical to the old compiler on the corpus and the reference encodings. (#17)

## Compiler rewrite (#17)

`gs2/compile.rs` is now a `gs2/compile/` module. It has a lexer, a GS2 parser, a GS1 front end, the compiler's own AST, a single code generator, and tables. `tests/gs2_modes.rs` covers each quirk in both modes.

## GS1

- `obj.f(...)` is encoded as a real method call, the same bytes `compile_gs2` produces, instead of a call to a function named `this.f`. Joined classes now resolve on a real 4.208 client. (#18)
- GS1 lowering:
  - `seteffectmode` is supported.
  - `getplayer` is rewritten to `findplayer`.
  - Commands inside `with` bodies compile. (#13)
- The GS1 era is passed through, which fixes 35 Era units and 10 Joey units. (#16)

## GS2

- New syntax: new-blocks, dotted function names, chained assignment, `elseif`, const/enum, value assignments, and leaving a `with`. (#13)
- Codegen matches a reference GS2 compiler, found by black-box diffing. This includes the `pow()` argument order, and leaving out the trailing `return 0` after an if/else that always returns. (#11)
- It compiles every script the live servers ran. That covers GS1-style commands inside GS2, a missing end-of-line `;`, lambdas, and the remaining corpus failure shapes from v5 and v6. (#14, #15, #16)

## Runtime

- `return a;` returns `a`'s value instead of 0. (#16)
- `EffectHost` gains `strequals` and `seteffectmode`. (#16)
