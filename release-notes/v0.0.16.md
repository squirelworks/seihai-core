Logging out when the game window closes.

## Breaking changes

- **`client::Live` has one more field**, `closed`. A struct literal of `Live` needs it; `..Default::default()` fills it.

## Client

- `Live::closed`: a view sets it when its window closes, and the network thread in `run_with` closes the connection within a walk tick and returns. Before, the player stayed logged in until the process ended, so going back to the start window and joining again was refused as a double login (seihai #475 lab).
