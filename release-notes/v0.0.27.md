The Mac PowerPC 4.04r2 and 5.12 get their own PLO sets, and 4.20r6 and 4.20r8 step the frame cipher rounding down.

## Breaking changes

- **`ClientVersion::V404R2Mac` and `V512Mac` have their own PLO sets.** 4.04r2 Mac takes 97 ids (the Windows 4.04r2 set without 41); 5.12 Mac takes 101 (the Mac 4.20r6 set plus 140 and 197, so against the Windows 5.12: 41 out, 100 and 108 in). The 4.20r6 and 5.24r4 sets are unchanged; only their deltas in the chain moved.
- **4.20r6 and 4.20r8 now set `gen5_round_down`.** Before, 4.20r6 reset it to round-up. The two roundings only differ for a compressed body under 16 bytes whose length is not a multiple of 4, and 4.x clients compress only bodies over 47 bytes.

## Protocol

- The Mac 4.20r6 thresholds match 4.04r2 and 5.12: bz2 above 4095 bytes, zlib above 47.
- 5.00r7 was not read and stays round-up, marked unknown. The Windows 4.04r2 row is unchanged.
- `profile_toml.tsv` and `documentation/version-chain.{md,tsv}` are updated to match.

## Checks

- A new test in `protocol::profile` checks the three Mac PLO sets id by id; `difftest::decode` checks the round-down rows.
