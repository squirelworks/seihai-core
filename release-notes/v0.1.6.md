Every login token Graal_analysis's catalogue (`client-internals/version-token-catalogue.md`) records is now in seihai-core, so the other Seihai repos can take their token lists from one place.

## Additions

- `protocol::KNOWN_TOKENS` / `known_token(token)`: 78 tokens, each with its evidence grade (`TokenGrade`: wire, binary, binary + lab login, list only, server-defined), what it is sent for (`TokenKind`: game, listserver hello, RemoteControl, Graal3D, server script), the builds that send it, and the `ClientVersion` profiles that present as it. 32 of the tokens have no profile (26 of them game logins), among them 1.40 `GNW23090`, the Linux 3.x/4.x/6.x builds, the 6.x betas, the Mac 6.015 and the real Mac 4.20r6 `G3D21126`.
- `protocol::tokens_tsv()` and the generated `documentation/version-tokens.tsv`. A unit test fails when the file is stale; `cargo test -p seihai-core write_version_tokens_tsv -- --ignored` rewrites it.

## Documentation

- `ClientVersion::V420R6` says what the catalogue found: the Mac build labelled 4.20r6 (`G3D27076`) is a 4.10r2/4.11-era build, and the real Mac 4.20r6 sends `G3D21126`. The variant and its label are unchanged.
- The README says the version tokens and the version chain live only in this repo.

No API changes beyond the additions.
