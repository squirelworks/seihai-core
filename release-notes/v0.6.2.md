# 0.6.2

## GS1 to GS2: `#s(name)` on a plain string

`#s(door)` used to be refused. A plain GS1 string is a player flag, which
`setstring` sends as `client.gs1_door` and seihai-gserver keeps as
`door`, so it now reads `player.door`, the same way a plain flag read
lowers (lab 2026-11-13 for flags; for strings **[inf]**). `local.` and
`server.` strings, and a plain name built at run time, are still refused.

## Fuzzing (#80)

Two new targets: `session_apply` (every server→client decoder behind
`SessionState::apply`, as 2.05, 2.22 and 5.12) and `gs2_exec` (the GS2
executor on any bytecode the reader takes). All 13 targets ran for four
minutes each with no crash. `gs1_parse` found a timeout: commas nested in
parentheses retried each other's `, b in |lo,hi|` look-ahead, so the GS1
parse time grew about sevenfold per level. The parser now remembers a
comma where the look-ahead failed, and the regression test parses twelve
levels at once.

## Compatibility

No API changes. Scripts that used `#s(name)` on a plain string, which were
refused, now compile.
