The shared client session hands the view the player's weapons, for the item list (Q) and the weapon key (D) that Ato and Issho now have, and other players' bombs, arrows and throws.

## API

- `client::Live::weapons` (`SharedWeapons`): the network thread writes the player's weapons there when they change, as `OwnWeapons { defaults, named }` (the `PLO_DEFAULTWEAPON` ids, and the server weapons with their image and GS1 script).
- `OwnWeapons::names` lists them in the 2.05 item-list order: built-in weapons first, then the server's, with hidden (`-`) and repeated names left out.
- `client::Live::level_objects` (`SharedLevelObjects`): other players' bombs, bomb removals, explosions and arrows, in the player's own cell's coordinates, for the view to draw and run. The network thread now drains `SessionState::level_objects`, which no client session took before (the baddies in it are dropped).
- `client::Live::throws` (`SharedThrows`): other players who threw what they carried, as `OtherThrow { id, sprite, x, y, dir }`.
- `client::default_weapon_name(id)`: `Bow`, `Bomb`, `Superbomb`, `Fireball`, `Fireblast`, `Nukeshot`, `Joltbomb` for their ids.

`Live` gains three fields. Every consumer in the suite builds it with `Live::default()`, so this is a patch release; a `Live { .. }` literal would need `..Default::default()`.
