seihai-core can now read and write the classic character files that Graal Character Designer 1.2.7 and GChar 1.0 (1999) save, `.chr` and `.chi`.

## Changes

- New module `assets::chr`, with `Character { name, head, female, colors }`.
- `Character::parse` reads the one-line file, for example `CHR:1.00Blade=head189.gif,male,black,black,gray,gray,red`. The five colours are colour-list names in prop 13's order (skin, coat, sleeves, shoes, belt), and `grey` is read as `gray`. A missing magic, a wrong field count, an unknown sex or an unknown colour is refused, with a message naming it.
- `Character::write` writes the line back.
- `Character::looks` gives the head and colours as `looks::Looks` on the default body, so a client or tool can draw the character through the existing body recolouring.
- Re-exported as `assets::Character` and `CHR_MAGIC`.

The sample `.chr` files are third-party files, so the tests use lines written for them.

No breaking API changes.
