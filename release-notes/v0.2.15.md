# GS1 per-event prefix execution

GS1 scripts with unconditional executable code before named event tests
now use the existing whole-script dispatcher. Prefixes run before each
named event rather than during the GS2 load pass only. Eventless scripts
retain load-time execution; direct GS2 public functions and Machine entry
points are unchanged. The suffix-call fix from 0.2.14 is retained.

Synthetic tests cover Created/Timeout prefix replay, eventless loading,
direct public calls and sleep continuation. This corrects the documented
internal GS1 contract, not a claim of native-client or all-version parity.
Unnamed-event wrappers and suffix-command semantics remain outside this fix.

No public API signature changes.
