Strict GS2 accepts the loose spellings the engine's own compiler accepts, and Detect reads GS1-looking scripts as GS1 again.

## Breaking changes

- **`engine::ast::Stmt::Assign`, `IncDec` and `Call` carry a `line`.** Code that builds or matches them field by field needs the new field or `..`.
- **Strict mode accepts tolerated quirks.** A stray `;`, an unterminated `/*` at the end of the file, `elseif`, `<>`/`=<`/`=>`/`:=`, a function body without braces, a function with no body and a call of a call's result now compile in strict mode, each with a warning. Any other quirk still errors.
- **Detect tries GS1 (or GS1 2.1) before GS2** for a script that looks like GS1, undoing the order from #17. About 589 Era units on the corpus move back to GS1 2.1.

## Scripting

- `Quirk::tolerated()` names the quirks strict mode accepts. The list comes from one-quirk probes, each with a clean twin, run through two reference GS2 compilers as black boxes: a quirk is tolerated when both accept it with the same bytes as the clean spelling.
- When both fronts fail, Detect reports both errors.
- GS1 lowering errors name the line of the statement they come from.

## Checks

- `tests/gs2_modes.rs`: each tolerated quirk compiles in strict mode with a warning and the clean twin's bytes; the other quirks are still refused.
