The built-in default player is now a squirrel, Seihai's mascot. A Graal file the user places in their asset folder still replaces each default, file by file, as before.

## Changes

- `assets/default/heads/head0.png` (and `.gif`): a squirrel head with tufted ears, big eyes, a cream muzzle and buck teeth, in all four directions.
- `assets/default/bodies/body.png` (and `.gif`): orange-brown fur with a cream belly and paws and a bushy tail, in every pose (idle, walk, sword, sit, hurt, carry, lying). The 2.05 colour layout is kept, so a player's colours still recolour the body; the tail has its own palette entries and keeps its colour.
- `assets/default/state.png`: an acorn in place of the rupee icon. `assets/default/shields/shield1.png`: an acorn emblem.
- The head PNG is written 4-bit again (newer Pillow kept it 8-bit).

All of it is original, generated by `tools/gen_default_assets.py` in the seihai repo (see `documentation/default-assets.md` there). Sheet sizes, cell layout and palette sizes are unchanged. The built-in set's id (CRC-32 of the set) changes, so the set is written to a new `<settings dir>/builtin/<id>/` folder on first start.

No API changes.
