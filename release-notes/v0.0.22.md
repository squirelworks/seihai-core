The Mac PowerPC 4.04r2 and 5.12 as client versions of their own.

## Breaking changes

- **`ClientVersion::V404R2Mac` and `ClientVersion::V512Mac`** are new variants, so an exhaustive `match` on `ClientVersion` needs arms for them.
- **`Protocol` has one more field**, `gen5_compress_all`. A struct literal of it needs the field.

## Protocol

- New profile rows for 4.04r2 Mac (`G3D18026`) and 5.12 Mac (`G3D15097`). Both were read from the Mac OS X PowerPC programs and lab-run unchanged on Mac OS X 10.4. They log in with `mac` and two machine hashes, and 5.12 Mac adds the quoted Darwin kernel string as a fifth field (`LOBBY_404_MAC`, `LOBBY_512_MAC`, `MAC_TIGER_KERNEL`). Their own props after login are `OSTYPE` `mac` and `TEXTCODEPAGE` 0 (`LOBBY_LOGIN_MAC_PPC`).
- Both Mac builds use 5.12's round-down gen-5 cipher step. The new `Protocol::gen5_compress_all` keeps "compress every frame" for the Windows 5.12 only.
- `documentation/version-chain.md` and `.tsv` are regenerated.
