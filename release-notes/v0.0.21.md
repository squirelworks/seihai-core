GS1 per client build: each version scripts with its own command table, and the 1.x–2.1 engine's condition and message-code rules.

## Breaking changes

- **`scripting::engine::Era` has one variant per GS1 command table** (25, from `V121` to `V500`), read from the client binaries (Graal_analysis `npc-library/gs1-commands-by-version.tsv`, 61 builds). `Era::V21` now means 2.1 itself (no binary: NewWorld beta 2's table plus `play2`); the 2.17.1–2.31 table is `Era::V217`. Code that passed `Era::V21` to mean "the newest GS1" should pass `Era::V217`.
- **`Cmd` lookups honour removals**: `vocab::ABSENT` lists `seteffect` (gone in 1.34–1.41r1), `unseteffect` (1.21–1.33 only), the six commands the C++ engine never registered, and `savelog` in 3.04.

## Scripting

- 1.21–1.42 no longer borrow the 2.00 command set: 1.21 has 71 commands, 1.33 88, 1.41r1 126, NewMain 1.42 134. A unit test checks every era's count against the build tables.
- The 28 commands Seihai lacked are added with the letters 2.17.1/2.22/2.31 register (the same as 3.04's): `putnpc2`, `showimg2`, `showtext2`, `showani`/`showani2`, `showpoly`/`showpoly2`, `wraptext`/`wraptext2`, `shoot`, `setshootparams`, `serverwarp`, `sendpm`, `setpm`, `sendtonc`, `sendtorc`, `savelog`/`savelog2`, `setcursor`/`setcursor2`, `enablemap`/`disablemap`, `enablepause`/`disablepause`, `changeimgmode`, `unseteffect`, and 5.00r7's `setspritesimage`/`setstatusimage`. `showtext` takes `RRRSSS`.
- Dates corrected from the tables: `showtext` and `hideimgs` (2.17.1), `openurl2` (2.01), `move` (2.03), `setz` (2.05), `addstring` (NewWorld beta 2), and every 1.x command. Before 2.1 `addstring` is not a command (the old "appends text" rule had no source).
- Statement words are gated too: `while` from 1.28 beta 2, `function`/`return`/`break`/`continue` from 1.41r1, `with` in 2.17.1–3.04 only. A statement a build lacks is read and skipped with a diagnostic.
- `if (1)` and `if (0.5)` are false in every build (a bare number is a flag name), as the real 1.41r1, 2.05r2, 2.17.1, 2.22 and 2.31 clients showed.
- Before 2.17 a comparison of two constants is 0 (`1==1`, `(1+0)==1`), as 1.41r1 and 2.05r2 do; 2.17.1 and later compare normally.
- Before 2.17 the message expander turns `##` into `#`, makes `#b` and an argument-less `#v`/`#s` empty, and drops the `#` of a code it does not know (`A#?B` is `A?B`, and 1.41's `#e(1,2,x)` is `e(1,2,x)`). From 2.17 unknown codes stay as written. `#K(n)` is a code from 2.00, `#F` from 2.17.
- Events, flags, variables and functions are not yet gated per 1.x build: 1.x keeps the 2.00 set. Fixes from the string tables: `onmapx`/`onmapy` from 2.03, `getnpc`/`getplayer` from 2.17.

## Not done

- What the new 2.17 codes return in a populated context (`#F`, `#S`, `#D`, `#I`, `#R`, `#P6`–`#P9`, `#C6`, `#C7`), and `##` in the 2.17 engine.
- `while (1)` was not run on a real client, so loops keep the plain number.
