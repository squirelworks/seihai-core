seihai-draw can now draw text in a TrueType or OpenType font. Tools need it for GraalShop's TEXT actors in movie mode (servertools #78) and for labels.

## Changes

- New in seihai-draw: `draw_text(dst, font, text, x, y, &TextStyle)` and `measure_text`.
- `TextStyle` sets the pixel size, colour, bold, italic, underline, strikeout, shaded, alignment (`Align::Left`, `Center`, `Right`) and wrapping at spaces (`wrap: Some(width)`).
- Glyphs use the font's advances and kerning, and their coverage is blended over the buffer.
- Bold, italic, the shadow and the lines are drawn by hand: a one-pixel second pass, a lean of a fifth of the height, a black copy at +1,+1, and rules. One regular face is enough.
- The font is the caller's. No font file is bundled.
- `ab_glyph` is a new dependency (Apache-2.0) and is re-exported as `seihai_draw::ab_glyph`, so a caller can write `ab_glyph::FontVec::try_from_vec(bytes)` without depending on it directly.

The tests use a small built-in font of square glyphs, so they need no font file. They cover the baseline and box size, wrapping with right alignment, underline, shadow and bold.

No breaking API changes.
