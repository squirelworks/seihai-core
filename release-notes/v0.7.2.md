# 0.7.2

## PLO_FILE mod time for 2.05 and the NewWorld betas

`files.modtime` (and so `ClientVersion::file_has_modtime`) is now yes for 2.05 and both NewWorld betas (`NewWorldB1`, `NewWorldB2`). Real 2.05 rev 2 and both betas take a served file only with the GINT5 mod time and the closing line end. Sent without them, the file is dropped, so an NPC whose image the server sends has no size, can't be touched, and its `toweapons` never runs. Seen in Wine labs against seihai-gserver on 2026-11-05 (2.05 rev 2) and 2026-11-20 (nwb1 and nwb2). GServer counts the mod time from 2.1 on, and the NewWorld beta 2 row had set it back to no from a static read of 2.1 test 3. The labs show both were wrong for these builds.

The `PLO_FILE` modtime row in `packet-layouts.tsv` now starts at 2.05. The NewWorld rows' COLORS note names bytes 6 to 8 (pullover, pants, border, from the beta readme) and says how a server fills them from the classic five.

## Compatibility

No API changes. Only a profile value changes: seihai-gserver can drop its 2.05 and NewWorld mod-time overrides once it, seihai-npcserver and seihai-rc repin this tag together. 2.05 rev 0 and rev 1 were not lab-checked; they share the 2.05 row.
