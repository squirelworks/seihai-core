The shared client session hands the game the floor items the server puts down and takes away, so Ato and Issho see other players' drops and the items the server rolls, and can pick them up.

## API

- `client::Live::items` (`SharedItems`): the server's `PLO_ITEMADD` and `PLO_ITEMDEL` as `protocol::ServerItem`, in the order they came, for the game to apply with `OfflineSession::add_server_item` / `remove_server_item`. The network thread now drains `SessionState::items`, which no client session took before.

`Live` gains one field. Every consumer in the suite builds it with `Live::default()`, so this is a patch release.

## Consumers

seihai moves to `v0.1.4` with the PR that takes the server's floor items in seihai-play.
