# 0.5.0

Level NPCs that mix GS1 event tests with GS2 event functions now run both
parts. The 2019 Delteria backup has 300 such NPCs in 100 levels; 292 hold
both `if (created)` and `function onCreated()`, most as the editor stub
`if (created) dontblock;` next to a `function onCreated()` that calls
`dontblock()` and moves the NPC by `.5`. Before this release one of the two
parts was lost:

- **Unmarked scripts** (`Language::Detect`) with a `function` were read as
  GS2, where a top-level `if (created)` tests a variable once at load and
  never runs. Read as GS2, an unmarked script now lifts each top-level
  GS1 event test into that event's function, with a new
  `Quirk::Gs1EventTest` warning.
- **The GS1 front end** (and so `delivery`) made a lifted `onCreated` next
  to the script's own `function onCreated` (lower-cased by GS1). The
  client calls the first handler it finds, so one of them never ran.

Both front ends now fold the lifted GS1 code into the script's own handler
for the event, matched without regard to case or `public.`. The GS1 code
runs first. GS1 code that can `return` keeps a helper function of its own,
which the handler calls first, so its `return` does not skip the GS2 code.
This is Seihai's reading of these NPCs; no original client run has
confirmed it yet. A script marked GS2 is unchanged: its `if (created)`
stays a variable test, as gs2-parser reads it (issue 32).

Tile layers: `Level::tile_id_on_layer` and `Level::tile_layers` read the
upper tile layers. Tile 4095 (`//` in a `BOARD` row) is the empty marker
on layers 1 and up, so an uncovered cell and a cell written as 4095 read
the same. `seihai-draw` no longer paints 4095 cells on upper layers as
tile (127, 31): an editor-saved blank layer 1 or 2 used to cover the whole
level with that tile.

Tests: `tests/mixed_npcs.rs` with synthetic fixtures in
`tests/fixtures/mixed` (shapes from the Delteria counts; no Delteria text),
including a level with sparse layer-1/2 patches and a level with blank
full-width upper layers, both through `GR-V1.05` and back.

## Breaking changes

`Quirk` is a public exhaustive enum and gains `Gs1EventTest(String)`.
Downstream exhaustive matches must handle it. `Language::Detect` compiles
mixed GS1/GS2 scripts to different bytecode than 0.4.x (the GS1 part now
runs), and the GS1 front end merges the handlers it used to emit twice.
