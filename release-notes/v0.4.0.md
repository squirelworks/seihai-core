# 0.4.0

The GS1 parser can explicitly select the observed 1.40 / 1.40 rev 1
vocabulary with `Era::V140`; `gs1c --era 1.40` uses the same selection.
Its 125 registered words sit between 1.39's 111 and 1.41 rev 1's 126.
Only the fourteen documented registration floors move earlier;
`showstats` still starts at 1.41. See `documentation/gs1-era-140.md`
for the pinned public matrix and scope of the static evidence.

## Breaking changes

`Era` is a public exhaustive enum and gains `V140`. Downstream exhaustive
matches must handle that variant before adopting 0.4.0. Core's label
match and `Era::ALL` are updated, so explicit parser and compiler-example
selection work. Existing `ClientVersion` mappings continue to select
their previous eras; no online 1.40 profile is added.

Argument signatures and execution use Seihai's existing implementations.
This is not evidence of native 1.40 argument, effect or timing semantics.
The existing measured timeout gate still begins at 1.41. The 0.3.1
identity/provenance notes and runtime profile values are preserved.
