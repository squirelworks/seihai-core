The iPhone clients' login tokens join `KNOWN_TOKENS` and `documentation/version-tokens.tsv`, from Graal_analysis `client-internals/iphone-version-tokens.md`.

## Changes

- **`G3D04048`** (B): Belote 1.2 and 1.50 (Quattroplay Belote Expert Online, 2008), read from both IPAs. gs2lib names this token "iPhone 1.1".
- **`G3D0208A`** (B): GraalOnline Classic+ 1.13 for iPhone, read from its IPA. gs2lib has no entry for it.
- **`G3D18010`, `G3D29090`, `G3D2504D`** (L): gs2lib's "iPhone 1.5", "iPhone 1.11" and "iPhone Belote 1.5". No binary has been read for these.

None has a profile. No API changes.
