A file the server sends with no extension in its name is taken. The Graal3D Sky asks for its textures that way (`sky_fr`, `sky_up`, ...), and the lab gserver answers with that name, so Ato's 3D login now reaches step 6 (seihai #458).

## Fixes

- `PLO_FILE` (102) with a name that has no `.` was dropped, because the reader took a missing dot as the sign of the wrong layout. The file's request also stayed in the four-request window, so later requests never went out. Now a name with no dot is taken when neither layout reads a dotted name, in the connection's layout first. A dotted name still decides the layout as before.

No API changes.
