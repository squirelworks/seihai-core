seihai-core can now read every frame of an animated GIF, not only the first. Together with 0.2.3's MNG writer this gives seihai-servertools a gif2mng: animated GIFs from old worlds become the MNG animations the client plays.

## Changes

- `assets::read_gif_frames(bytes)` returns `GifFrames { frames, loops }`. Each frame is an `IndexedFrame` the size of the logical screen, built over the frame before as its disposal method leaves it (keep, clear to the background, or back to the frame before). It carries the frame's colour table, its transparent index and its delay in milliseconds. `loops` is the `NETSCAPE2.0` loop count, `Some(0)` for ever and `None` when the file has none.
- A cleared or uncovered pixel takes the frame's transparent index, or the screen's background index when the frame has none.

`read_gif_rgba` is unchanged: the client still draws the first image only.

Tests read a hand-built three-frame GIF with a partial frame, a cleared frame and a loop block, and the one-frame sample.

No breaking API changes.
