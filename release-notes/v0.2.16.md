# GS1 suffix command ordering

Commands after a named event test now use the existing whole-script
dispatcher instead of running in the GS2 load pass before the handler.
For example, a creation handler setting chat to `event` followed by
`setcharprop #c,suffix;` now finishes with `suffix`, in source order.

A baseline-red/fix-green synthetic regression covers that supported command,
a dispatcher-forcing assignment control and an event-only control, with
repeated Created delivery. This is internal compiler/VM evidence, not a
native-client result or proof of every command's compatibility.

Machine entry points, direct GS2 public calls, eventless scripts, command
support and unnamed-event wrapper coverage are unchanged. No API changes.
