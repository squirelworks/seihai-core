# GANI PARAM1 placement preservation

Primary evidence receipt [IOS-GANI-PARAM1-20261115-04](https://github.com/squirelworks/Graal_analysis/blob/01441a756c39bbea58600c3660b6bf72b8b42df8/formats/ios-gani-param1-placements.md) (static shipped-file structural observation, reviewed by the corpus lead; published in unmerged research PR #503) reports uppercase PARAM1 as the first token of a three-field ANI placement group in Classic+1.13 and Era+1.0. The observed forms use SINGLEDIRECTION, two comma groups and positive integer coordinates. This is file-structure evidence, not a native playback observation. No original resource contents are included here.

GaniPlacement now stores GaniPlacementReference rather than a numeric-only sprite_id. Sprite(0) and Param1 are distinct. The reference implements Display for downstream serializers. The drawing helper resolves only Sprite references; Param1 is skipped until its native resolution contract is established. Other slots, ATTR placement syntax, case variants and native coordinate acceptance are not established by this change. Existing numeric parsing remains unchanged.

Known consumer migration: seihai-draw matches the reference explicitly. Servertools lat-core gani encoder must serialize reference instead of sprite_id, and numeric assertions must use Sprite variants. Its existing pinned dependency is unaffected; migrate the encoder and paired dependency pins in a separate PR after an owner-approved core release/tag. No tag is created here. Seihai also requires migration of direct placement-ID uses in crates/seihai-mae/src/render/tiles.rs and assertions in crates/seihai-mae/tests/default_assets.rs. Match Sprite explicitly and leave Param1 unresolved; do not coerce it back to zero. Existing pinned consumers remain unaffected until their dependency changes. This inventory is bounded, not an assertion that every downstream caller has been located.

Independent synthetic parser fixtures distinguish PARAM1 from numeric zero in either comma-group position. A synthetic drawing control draws numeric zero from a one-pixel sheet while unresolved PARAM1 remains transparent. These tests establish this implementation's preservation and fallback only, not native rendering, slot resolution, timing or GANI0002 units.
